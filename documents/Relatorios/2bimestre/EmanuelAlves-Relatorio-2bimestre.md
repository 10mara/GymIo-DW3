# 📄 Relatório Individual – Projeto GymIO (2º Bimestre)

## 👤 Integrante: Emanuel  
**Função:** Desenvolvedor Full Stack

---

## 1. Atividades Realizadas no Projeto

Durante o segundo bimestre do projeto GymIO, atuei como desenvolvedor Full Stack, participando principalmente do desenvolvimento do frontend da Tela Principal (Dashboard) e da Tela de Controle de Acesso (Catraca), além de colaborar na integração dessas interfaces com o backend desenvolvido pela equipe.

Na implementação do Dashboard, fui responsável por desenvolver a interface principal do sistema, utilizando como base o protótipo definido anteriormente. Desenvolvi os componentes responsáveis pela apresentação das principais informações da academia, como indicadores gerais, cartões informativos, tabelas e elementos de navegação. Busquei manter um padrão visual consistente com as demais telas do sistema, priorizando organização, usabilidade e facilidade de acesso às informações.

Também desenvolvi o frontend da Tela de Controle de Acesso (Catraca), responsável pelo registro das entradas e saídas dos alunos na academia. Essa tela foi construída de forma a facilitar a utilização pelos funcionários, permitindo a consulta rápida dos registros e a visualização do histórico de acessos.

Além do desenvolvimento das interfaces, participei da integração dessas telas com as APIs desenvolvidas no backend, realizando testes para garantir o correto envio e recebimento dos dados. Durante esse processo, trabalhei em conjunto com os desenvolvedores responsáveis pelo backend para ajustar requisições, validar respostas da API e garantir que todas as funcionalidades estivessem operando corretamente.

Também auxiliei em correções gerais do sistema sempre que necessário, contribuindo na identificação e resolução de problemas relacionados ao frontend e à integração entre as diferentes partes da aplicação.

---

## 2. Conhecimentos Adquiridos

Durante este bimestre, aprofundei meus conhecimentos em desenvolvimento Full Stack, principalmente na integração entre frontend e backend em aplicações web.

No frontend, desenvolvi maior domínio na utilização do React para construção de interfaces mais organizadas e reutilizáveis, aprendendo a estruturar melhor os componentes e separar responsabilidades dentro da aplicação. Também adquiri experiência na implementação de layouts administrativos, utilizando tabelas, cards, formulários e elementos de navegação de forma mais eficiente.

Na integração com o backend, compreendi melhor o funcionamento das APIs REST, aprendendo como consumir rotas, tratar respostas, enviar informações para o servidor e lidar com possíveis erros durante a comunicação entre cliente e servidor.

Além dos conhecimentos técnicos, também desenvolvi habilidades relacionadas ao trabalho em equipe, organização das atividades e colaboração entre os diferentes integrantes do projeto, compreendendo a importância da comunicação para garantir uma integração eficiente entre os módulos do sistema.

---

## 3. Dificuldades Encontradas

Durante o desenvolvimento das atividades, algumas dificuldades surgiram principalmente na integração entre as interfaces desenvolvidas no frontend e as APIs disponibilizadas pelo backend.

Em determinados momentos, foi necessário adaptar componentes devido a alterações nas estruturas dos dados retornados pelas APIs, exigindo ajustes tanto na interface quanto na forma de realizar as requisições.

Outra dificuldade encontrada esteve relacionada à implementação de componentes reutilizáveis, buscando manter um padrão visual consistente entre as telas sem comprometer a organização do código.

Também houve desafios na realização dos testes de integração, principalmente quando algumas funcionalidades dependiam da conclusão de módulos desenvolvidos por outros integrantes da equipe.

---

## 4. Como as Dificuldades Foram Resolvidas

As dificuldades foram solucionadas por meio de testes constantes e comunicação frequente com os integrantes responsáveis pelo backend. Sempre que necessário, foram realizados ajustes nas requisições e na estrutura dos componentes para garantir compatibilidade entre as diferentes partes do sistema.

Também foram realizadas pesquisas em documentações oficiais e consultas a materiais de apoio para compreender melhor o funcionamento das bibliotecas utilizadas e aplicar boas práticas de desenvolvimento.

Durante a construção das interfaces, optei por organizar os componentes de forma modular, facilitando futuras manutenções e permitindo maior reaproveitamento de código.

A colaboração com os demais membros da equipe também foi fundamental para solucionar problemas de integração e garantir que as funcionalidades fossem entregues conforme o planejamento estabelecido.

---

## 5. Considerações Finais

A participação no segundo bimestre do projeto GymIO contribuiu significativamente para o meu desenvolvimento como desenvolvedor Full Stack. A experiência permitiu consolidar conhecimentos relacionados ao desenvolvimento de interfaces modernas, integração entre frontend e backend e organização de aplicações web.

Além disso, o trabalho em equipe proporcionou uma compreensão mais ampla sobre o desenvolvimento colaborativo de software, evidenciando a importância da comunicação, da organização e da integração entre os diferentes módulos do sistema.

De forma geral, considero que as atividades desenvolvidas durante este período foram fundamentais para ampliar meus conhecimentos técnicos e fortalecer minhas competências para futuros projetos na área de desenvolvimento de software.
