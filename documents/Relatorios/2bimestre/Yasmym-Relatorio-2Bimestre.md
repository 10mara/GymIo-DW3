# 📄 Relatório Individual – Projeto GymIO (2º Bimestre)

## 👤 Integrante: Yasmym Lemes  
**Função:** Desenvolvedora Frontend

---

## 1. Atividades Realizadas no Projeto

Durante o segundo bimestre do projeto GymIO, atuei como desenvolvedora frontend, sendo responsável pelo desenvolvimento das interfaces dos módulos de **Funcionários** e **Equipamentos**, seguindo o protótipo estabelecido pela equipe e mantendo a identidade visual do sistema.

Na tela de **Gerenciamento de Funcionários**, desenvolvi toda a interface responsável pelo cadastro, consulta, edição e visualização dos colaboradores da academia. Trabalhei na implementação da estrutura da página, organização dos componentes, criação dos formulários, tabelas e modais utilizados nas operações do sistema. Também busquei manter uma navegação intuitiva e uma organização visual que facilitasse o trabalho dos usuários responsáveis pelo gerenciamento dos funcionários.

Além disso, fui responsável pelo desenvolvimento da interface da tela de **Controle de Equipamentos**, implementando os componentes necessários para o gerenciamento dos equipamentos utilizados pela academia. Desenvolvi a estrutura da tabela de equipamentos, os formulários de cadastro e edição, os modais para visualização das informações e os elementos responsáveis pelo controle das manutenções dos aparelhos.

Durante o desenvolvimento dessas telas, procurei manter o mesmo padrão visual adotado nas demais páginas do sistema, reutilizando componentes já existentes sempre que possível e realizando ajustes para garantir uma interface consistente em toda a aplicação.

Também participei da integração das telas com as APIs desenvolvidas pelo backend, realizando testes para validar o correto funcionamento das funcionalidades e ajustando a interface sempre que necessário para garantir uma boa experiência ao usuário.

Ao longo do desenvolvimento, colaborei com os demais integrantes da equipe, realizando alinhamentos sobre a estrutura das telas, organização dos componentes e adaptações necessárias para integrar corretamente o frontend às funcionalidades implementadas no backend.

---

## 2. Conhecimentos Adquiridos

Durante este segundo bimestre, aprofundei meus conhecimentos em desenvolvimento frontend, especialmente na construção de interfaces administrativas utilizando React.

Desenvolvi maior domínio na criação de componentes reutilizáveis, organização da estrutura das páginas e implementação de layouts mais completos e funcionais. Também adquiri experiência na construção de tabelas dinâmicas, formulários, modais e filtros, compreendendo melhor como organizar grandes volumes de informações de maneira clara e intuitiva.

Outro aprendizado importante foi relacionado à integração entre frontend e backend. Passei a compreender melhor como consumir APIs REST, tratar os dados recebidos e realizar validações antes da apresentação das informações ao usuário.

Além dos conhecimentos técnicos, desenvolvi habilidades relacionadas ao planejamento das interfaces, organização visual e trabalho em equipe, entendendo a importância da padronização dos componentes para facilitar a manutenção e evolução do sistema.

---

## 3. Dificuldades Encontradas

Durante o desenvolvimento das atividades, uma das principais dificuldades foi organizar telas que apresentavam uma grande quantidade de informações sem comprometer a usabilidade do sistema.

A construção da tela de Equipamentos exigiu atenção especial devido à necessidade de apresentar diferentes informações relacionadas aos equipamentos e às manutenções em uma mesma interface, mantendo uma organização clara para o usuário.

Também surgiram desafios durante a integração das telas com o backend, principalmente quando ocorreram alterações na estrutura dos dados retornados pelas APIs, exigindo adaptações nos componentes desenvolvidos.

Outro desafio foi manter a padronização visual entre todas as telas do sistema, considerando que diferentes integrantes estavam desenvolvendo interfaces simultaneamente.

---

## 4. Como as Dificuldades Foram Resolvidas

As dificuldades foram solucionadas por meio de pesquisas sobre boas práticas de desenvolvimento frontend, análise de sistemas administrativos como referência e realização de testes constantes durante a construção das interfaces.

Para manter a organização das telas, foram realizadas diversas revisões no posicionamento dos componentes, buscando melhorar a disposição das informações e facilitar a navegação dos usuários.

Durante a integração com o backend, trabalhei em conjunto com os desenvolvedores responsáveis pelas APIs para ajustar a comunicação entre as diferentes partes da aplicação, corrigindo inconsistências e garantindo o funcionamento adequado das funcionalidades.

Também foi adotado um padrão para os componentes utilizados em todas as telas, permitindo maior reutilização do código e facilitando futuras manutenções no sistema.

---

## 5. Considerações Finais

A participação no segundo bimestre do projeto GymIO contribuiu significativamente para o meu desenvolvimento como desenvolvedora frontend, permitindo aplicar conhecimentos em um projeto mais completo e próximo da realidade encontrada no mercado de trabalho.

O desenvolvimento das telas de Funcionários e Equipamentos possibilitou aprimorar minhas habilidades na construção de interfaces administrativas, organização visual e integração com APIs, além de reforçar a importância da padronização dos componentes em projetos desenvolvidos por equipes.

Além dos conhecimentos técnicos, a experiência fortaleceu competências relacionadas ao trabalho colaborativo, comunicação e resolução de problemas, tornando o desenvolvimento mais organizado e eficiente.

De forma geral, considero que este bimestre representou uma etapa importante da minha formação, proporcionando aprendizados que certamente contribuirão para minha atuação em futuros projetos de desenvolvimento de software.
